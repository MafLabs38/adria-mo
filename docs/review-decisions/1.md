# Review decisions of pull request #1 (initial scaffolding)

## R-1-1 | architecture | major | fixed

- **Finding**: the e2e smoke of the public site runs with the back end up, so it never proves the public part works with the back end down.
- **Where**: `.github/workflows/ci.yml`, job `e2e-smoke`.
- **Reason**: the back end is now stopped (its logs saved) before the Playwright smoke runs; the image checks (health, non-root user) stay before it.

## R-1-2 | architecture | major | fixed

- **Finding**: CODEOWNERS does not cover `CLAUDE.md`, `docs/spec.md` and `docs/review-decisions/README.md`, the rules the agents judge by.
- **Where**: `.github/CODEOWNERS`.
- **Reason**: added. Making code-owner review mandatory is a ruleset setting of `github-template`; it stays off while the maintainer is the only author (GitHub forbids approving one's own pull request), and is to be turned on when a second contributor gets write access.

## R-1-3 | architecture | major | fixed

- **Finding**: "open for N days" counts UTC days, while the building is in Paris, and the rule of "today" is undecided.
- **Where**: `web/src/lib/openSince.ts`.
- **Reason**: days are now counted in the Europe/Paris calendar (tests for winter and summer time and for midnight in Paris). Decided: the back end publishes the instant of the first observation and the browser computes the age against its own clock, so it keeps counting while the back end is down; the back end's KPIs will use the same time zone.
