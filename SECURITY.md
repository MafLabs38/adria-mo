# Security policy

Adria MO handles photos of a building's common areas, the accounts of its administrators and, later, anonymous contributions.

## Reporting a vulnerability

Please **do not open a public issue**. Use GitHub's private vulnerability reporting
(*Security* tab, *Report a vulnerability*). You will get an answer within a week.

## Scope

- The back end (`src/`) and its container image.
- The public site (`web/`).
- The CI workflows (`.github/workflows/`).

## What this repository never contains

Secrets, real photos, addresses, e-mail addresses or any data of an installation. If you find one, report it privately as above.
